About

This site is not documentation — it is a shared memory layer. LLMs do not retain context across platforms or sessions, so a stable, append-only log at a permanent URL becomes the substrate a model can read to recover context. Point a model at /llms.txt to give it the index.

Append-only by design. Entries are never edited; corrections are new entries that reference the one they supersede.
